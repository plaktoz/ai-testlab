# Mission: Building Adversarial Agents

## Why
Building secure AI systems requires knowing how to break them. This course develops the hands-on capability to construct automated red-teaming agents, exploit prompt injection vulnerabilities, and build adversarial training pipelines — so you can identify and close attack surfaces before they reach production. The outcome is not just theoretical understanding but an actionable toolkit for pre-deployment adversarial evaluation.

## Success looks like
- Design and implement an automated red-teaming agent that generates diverse adversarial prompts at scale
- Craft indirect prompt injection payloads targeting tool-use LLM agents
- Set up and run garak or PyRIT to scan an LLM application for known vulnerability classes
- Explain why standard safety training can fail against backdoored models and what latent adversarial training does differently
- Write a structured red-team plan for a real LLM application, including scope, attack types, success metrics, and data collection templates

## Constraints
- Learning from research papers — no access to proprietary systems or closed training pipelines
- Self-paced, one lesson at a time

## Out of scope
- Physical adversarial examples in computer vision (image perturbations)
- Cryptographic or network-layer security beyond LLM applications
- Formal verification or theorem-proving approaches to safety
- Deployment and MLOps (this course ends at the evaluation pipeline, not production serving)
