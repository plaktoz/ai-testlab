# HTML for Kids — Resources

## Knowledge

- [MDN Web Docs: HTML basics](https://developer.mozilla.org/en-US/docs/Learn/Getting_started_with_the_web/HTML_basics)
  The gold-standard beginner reference for HTML. Use for: accurate tag syntax, attribute names, semantic meaning.

- [MDN: HTML text fundamentals](https://developer.mozilla.org/en-US/docs/Learn/HTML/Introduction_to_HTML/HTML_text_fundamentals)
  Covers headings, paragraphs, bold, italic. Use for: lessons on text formatting (h1–h6, strong, em, p).

- [MDN: Getting started with HTML](https://developer.mozilla.org/en-US/docs/Learn/HTML/Introduction_to_HTML/Getting_started)
  Explains anatomy of an HTML element, nesting, attributes, and the basic page structure. Use for: lessons 1–2.

## Wisdom (Communities)

- [r/learnprogramming](https://reddit.com/r/learnprogramming)
  Beginner-friendly; large community for early-stage HTML questions.

- [CS Unplugged](https://csunplugged.org/en/)
  Activities for teaching computing concepts to young children without a computer. Use for: offline, playful reinforcement of concepts between sessions.
