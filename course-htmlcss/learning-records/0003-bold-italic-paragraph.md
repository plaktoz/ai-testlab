# Learning Record 0003 — Bold, Italic & Paragraph

## Session summary

Lesson 3 introduced three new tags in a single session, keeping scope tight for a 5-year-old learner.

## What was taught

| Tag | Concept |
|-----|---------|
| `<strong>` | Bold text that also signals importance to the browser |
| `<em>` | Italic (emphasis) text — expressive, not decorative |
| `<p>` | Paragraph — wraps a block of normal, flowing text |

`<p>` was introduced as a bonus callout rather than the primary focus, since the learner will need it immediately when building the About Me page (Lesson 5).

## Analogies used

- `<strong>` = shouting something important (voice bubble styled loud/bold)
- `<em>` = leaning in with feeling (voice bubble styled tilted/soft)

## Scaffolding note

`<b>` vs `<strong>` distinction was addressed directly: same visual output on screen, but developers prefer `<strong>` because it carries semantic meaning. A 5-year-old does not need to fully understand "semantic" — framing it as "it also tells the computer the word is important" was sufficient.

## ZPD assessment

Learner now has all the core inline text tools needed for a complete About Me page:
- Headings: `h1`, `h2`, `h3`
- Bold/emphasis: `strong`, `em`, `b`
- Paragraphs: `p`

Missing before the capstone: lists (`ul`, `li`). That is the only remaining building block for a well-structured About Me page.
