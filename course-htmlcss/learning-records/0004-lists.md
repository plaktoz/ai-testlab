# Learning Record 0004 — Lists

## Session summary

Lesson 4 introduced bullet lists: the final structural building block needed before the About Me capstone.

## What was taught

| Tag | Concept |
|-----|---------|
| `<ul>` | Unordered list — the "shopping bag" wrapper |
| `<li>` | One list item — always nested inside `<ul>` |

`<ol>` (ordered/numbered list) was referenced briefly in the cheat sheet as a sibling concept but not taught, to keep scope tight. The learner will encounter it naturally if they continue beyond this course.

## Analogy used

Shopping list: `<ul>` = the bag, `<li>` = each item in the bag. Concrete, immediately relatable for a 5-year-old.

## Indenting practice

The lesson explicitly demonstrated indenting `<li>` items inside `<ul>` using Tab. This is a coding habit worth forming early — it reduces confusion about nesting as pages grow more complex.

## ZPD assessment

The learner now has every tag needed for a complete About Me page:
- Skeleton: `html`, `head`, `body`
- Headings: `h1`, `h2`, `h3`
- Text: `p`, `strong`, `em`, `b`
- Lists: `ul`, `li`
