Hello, HTML! 👋

Learn the magic words that make web pages!

🏠 What is HTML?

HTML is the secret language computers use to show web pages.

Think of it like building a house with LEGO blocks.
Each LEGO block is a tag — a special word inside < pointy brackets >.

Every tag has a START and an END.
The end tag has a little slash / in it — like closing a box!

🧩 How a Tag Works

Here is a tag that makes text big and bold:

<b>I am super strong!</b>

The computer reads this as:

  • <b> — "Start making text bold"
  • The words in the middle show on the page
  • </b> — "Stop making text bold"
Tip for grown-ups: <b> stands for bold. It is one of the simplest HTML tags and a great first win.

✨ Every Web Page Has These 3 Magic Words

Every single webpage in the world starts with these three:

<html> <head> This is the page's secret information </head> <body> Everything you SEE goes in here! </body> </html>
📦
<html>
The big box that holds everything
🧠
<head>
Secret info (the page's brain)
👀
<body>
What you SEE on the page

✏️ Try It Yourself!

Let's make your very first web page! Ask a grown-up to help you save the file.

1
Open Notepad (Windows) or TextEdit (Mac). Ask a grown-up if you need help!
2
Type these magic words exactly — you can change "YOUR NAME" to your real name!
<html> <body> Hello! My name is <b>YOUR NAME</b>! </body> </html>
3
Save the file. Name it mypage.html — the .html part is very important!
4
Double-click the file to open it in your web browser. You made a real web page — well done! 🎉
What should you see? Your name should appear in bold in the browser — because you used the <b> tag!

📚 What Did You Learn Today?

  • HTML is the language of web pages
  • Tags look like <this> and always come in pairs
  • <b> makes text bold
  • Every page needs <html>, <head>, and <body>
