🛒 Think of a Shopping List

Imagine Mum writes a shopping list before going to the supermarket. Each item goes on its own line — milk, eggs, bread, apples.

🛒 Shopping List
  • Milk
  • Eggs
  • Bread
  • Apples

In HTML, a list works exactly the same way. You need two magic words to make one:

  • <ul> — the shopping bag that holds all the items
  • <li> — one list item (one thing in the bag)

✏️ How to Write a List

Put <li> items inside the <ul> bag:

<ul> <li>Pizza</li> <li>Ice Cream</li> <li>LEGO</li> </ul>
← You type this
  • Pizza
  • Ice Cream
  • LEGO
← Browser shows this
Remember: <ul> is the bag — it goes outside. <li> is each item — they go inside. Just like putting things into a bag!

💡 The Indenting Trick

Developers move <li> items to the right (press Tab) to show they are inside the <ul>. The browser doesn't care — but it makes the code much easier to read!

Hard to read: <ul><li>Cat</li><li>Dog</li></ul>
Easy to read: <ul> <li>Cat</li> <li>Dog</li> </ul>

✏️ Try It — Add Your Favourite Things List!

Open your mypage.html and add a bullet list of your favourite things. Here's what it should look like — fill in YOUR favourites!

<html> <body> <h1>My name is YOUR NAME!</h1> <h2>About Me</h2> <p>Hello! My name is <strong>YOUR NAME</strong>. I am <strong>5</strong> years old.</p> <h2>My Favourite Things</h2> <ul> <li>FAVOURITE THING 1</li> <li>FAVOURITE THING 2</li> <li>FAVOURITE THING 3</li> </ul> </body> </html>
1
Replace FAVOURITE THING 1, 2, 3 with things you truly love
2
Save and open the file — you should see a bullet list appear!
3
Want more items? Add more <li> lines inside the <ul>. You can have as many as you like 🌟

📚 What Did You Learn Today?

  • <ul> creates a bullet list — the "shopping bag"
  • <li> is one item in the list — always goes inside <ul>
  • Indent your <li> items with Tab to keep code tidy
