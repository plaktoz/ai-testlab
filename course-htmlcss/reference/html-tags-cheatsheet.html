HTML Tags Cheat Sheet

All the magic words you've learned — in one place!

Page Structure — Lesson 1

Lesson 1
<html> … </html>
The big box that wraps the whole page. Every HTML file starts and ends with this.
<html> everything goes here </html>
Lesson 1
<head> … </head>
Secret info about the page (title, language). Not shown on screen.
<head> secret stuff </head>
Lesson 1
<body> … </body>
Everything the user SEES goes inside here.
<body> hello world! </body>

Text Formatting — Lessons 1, 2 & 3

Lesson 1
<b> … </b>
Makes text bold (thick and heavy).
<b>I am bold!</b>
Lesson 2
<h1> … </h1>
The BIGGEST title. Use only once per page — it's the star!
<h1>My Page!</h1>
Lesson 2
<h2> … </h2>
A big section title. Use as many as you like.
<h2>About Me</h2>
Lesson 2
<h3> … </h3>
A smaller section title. Good for details inside an h2 section.
<h3>My Hobbies</h3>
Lesson 3
<strong> … </strong>
Makes text bold AND important. The computer knows this word really matters!
<strong>Watch out!</strong>
Lesson 3
<em> … </em>
Makes text italic — tilted sideways, showing feeling or emphasis.
<em>I love it!</em>
Lesson 3
<p> … </p>
A paragraph of normal text — a sentence or two that belongs together.
<p>Hello! I am five years old.</p>

Lists — Lesson 4

Lesson 4
<ul> … </ul>
An unordered list — the "shopping bag" that holds all list items. Makes bullet points.
<ul> <li>item</li> </ul>
Lesson 4
<li> … </li>
One list item. Always goes inside a <ul> (or <ol>). One per line.
<li>Pizza!</li>
