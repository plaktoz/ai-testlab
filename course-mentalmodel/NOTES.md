# Teacher Notes

## User preferences
- Explain everything as if talking to a 5-year-old: short sentences, no jargon, concrete images
- Always give 2–3 real-life examples per model (not textbook or abstract)
- Quiz must repeat until the user gets it right — never move on after a wrong answer
- Quiz answers should all be the same length to avoid giving away clues

## Teaching approach
- Start with the most popular / widely applicable models first
- One model per lesson
- Keep lessons very short — 5-minute read max
- Use the shared stylesheet and quiz widget for every lesson
