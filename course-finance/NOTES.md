# Teaching Notes

## Learner Profile
- Age: 5 years old
- Learning style: visual, interactive, story-based
- Attention span: ~10–15 minutes per lesson maximum

## Parent Preferences
- Make it interesting and interactive
- Many quizzes to confirm understanding
- Generate all lessons upfront (not drip-fed session by session)

## Pedagogical Approach
- Use bright colors, large fonts, emojis, and friendly characters
- Every lesson has a story setup before the knowledge chunk
- Quizzes use big clickable buttons — no typing
- Immediate feedback on every quiz answer (cheerful for correct, gentle redirect for wrong)
- Each lesson ends with a "real life challenge" for the child to try with a parent

## Curriculum Order
1. What is Money? (intro)
2. Coins and Bills (recognition)
3. Earning Money (chores = coins)
4. Needs vs Wants (choices)
5. Saving vs Spending (the piggy bank)
6. Saving for a Goal (delayed gratification)
7. Spend · Save · Give (the three-jar system)
